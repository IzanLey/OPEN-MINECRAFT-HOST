# API NeoForge

- `GET https://maven.neoforged.net/api/maven/versions/releases/net/neoforged/neoforge` → `versions[]`.
- Instalador: `https://maven.neoforged.net/releases/net/neoforged/neoforge/<v>/neoforge-<v>-installer.jar`.

La forma de elegir la versión (prefijo según la versión de Minecraft, descartar beta y alfa, quedarse la mayor) está en [[Core neoforge]].

Sin hash publicado.
