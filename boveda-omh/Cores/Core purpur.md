# Core purpur

`Fork de Paper con mas opciones. Plugins Bukkit/Spigot/Paper.`

| | |
|---|---|
| Edición | java |
| Versión mínima | 1.14.1 |
| `latest` | la última versión de la [[API Purpur]] |
| Complementos | plugins; Modrinth con `purpur, paper, spigot, bukkit` |

## Instalación
1. Comprueba que la versión esté en la lista: si no, `Purpur no tiene la version %s.`
2. Descarga `https://api.purpurmc.org/v2/purpur/<v>/latest/download` como `server.jar`, **sin hash**.
3. `start = {"type": "jar", "jar": "server.jar"}`.
